# Using GoldenHour

Updated 9 October 2026. Open https://goldenhour-aicup-2026-vk1007.web.app. No login or access code is needed.

## Start with immediate action

Choose your country, call the bank/official reporting channel, then start a report using “I have already sent money”. The app does not place calls automatically. If you have not paid, use the message check or the sourced warning-sign guide.

The call checklist, evidence upload, review, report pack, guidance and tracking remain reachable throughout the report. Country-specific transfer times use the receipt's local timezone. Unknown times stay unknown until the person provides them.

## Upload and review

Supported: PNG, JPEG, WebP, HEIC, PDF and plain text. Upload at most ten files per request; the country-specific limit is at most 7 MB per file. Remove a mistaken selection before uploading. Avoid uploading intimate images, passwords or OTPs.

Read the extracted reference, amount, date and recipient alongside each source quote. Correct uncertain fields. Masked account digits are never guessed. Repeated evidence can complete an existing transfer; conflicting values stay flagged. Confirm the disputed outgoing transfers. Unrelated credits are excluded from loss and hold drafts. Manual entry is available when extraction fails.

A source-checked label means the value matches the available source reading. It does not establish that a payment or document is authentic. The person remains responsible for reviewing their evidence.

## Prepare and follow up

Copy portal fields and the bank letter into the official reporting workflow. Incomplete or unconfirmed values keep the pack incomplete. The report detail view explains response priority and can prepare a hold-request draft limited to reviewed disputed debits. Only an authorized institution can execute a hold.

Record the acknowledgement received from the reporting channel. Follow-up dates can be viewed here and downloaded as an `.ics` calendar file. Import it into your calendar; reminders then depend on that calendar's settings. No SMS/WhatsApp delivery is active.

Guidance supports voice and typed questions. Browser microphone permission is needed for speech. Typed questions work without microphone permission, but still require the Live provider connection. If that connection fails, use the visible reporting instructions and document pack.

## Private access without login

Automatic random report credentials stay in this browser tab. Knowing a report ID does not grant access. Your reports lists only records whose credentials this tab holds, including unfinished reports. Closing the tab, clearing session storage, or changing browsers removes access; save your documents first. Case records expire after 30 days, with asynchronous physical deletion.

A 24-hour helper link grants a limited, masked view to anyone holding that link. Send it only to a trusted helper. Summary views exclude victim names, victim accounts, source quotes and free-text narrative. Text redaction is best effort, not a comprehensive privacy guarantee.

There are no stored incidents or simulated registry results. Warning-sign cards use official public advisories and do not generate reports. Payment records come from the person using the service.
